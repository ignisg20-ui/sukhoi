# Sukhoi Sky Battle

Аркадный воздушный бой в одном HTML-файле (Canvas 2D + WebAudio, без внешних зависимостей).
Просто открой `sukhoi-sky-battle.html` в браузере.

## Возможности
- **Вид со спутника** — рельеф сверху: плавные горы со снежными вершинами, скалы,
  леса, пляжи и вода (процедурный шум + рельефная подсветка), плюс облака над сценой.
- **Бесконечная карта** — камера летит за игроком, мир не имеет границ.
- **Реалистичный звук** — синтезированная турбина двигателя, очередь пушки, рёв ракеты,
  низкий взрыв и сигнал **захвата цели** 🔒 (WebAudio).
- **Каждый сам за себя** — самолёты-ИИ дерутся не только с игроком, но и друг с другом.
- **Захват цели и наведение** — наведи нос на врага, дождись захвата, ракета сама догонит.
- **Индикатор скорости** (км/ч), радар, переработанный HUD с числовым запасом прочности.
- **Повреждения** — дымный и огненный шлейф у битых машин, разлетающиеся обломки при уничтожении.

## Управление
- Клавиатура: `W`/`↑` тяга, `A`/`D` или `←`/`→` поворот, `S` тормоз, `Shift` форсаж,
  `Пробел` пушка, `F` ракета.
- Мышь: поворот к курсору, ЛКМ — огонь.
- Сенсор: левая половина экрана — джойстик, справа кнопки **ОГОНЬ / РАКЕТА / ФОРС**.

## Android (APK)
В папке `android/` — обёртка-приложение (WebView), которая показывает игру на весь экран
в горизонтальной ориентации. Игра берётся из единственного исходника `sukhoi-sky-battle.html`
(копируется в `assets` задачей `syncGame` перед сборкой).

Сборка APK:
```bash
cd android
ANDROID_HOME=/path/to/android-sdk ./gradlew assembleDebug
# результат: android/app/build/outputs/apk/debug/app-debug.apk
```
Нужен JDK 17 и Android SDK (platform 34, build-tools 34.0.0). Готовый debug-APK ставится
на телефон при включённой «Установке из неизвестных источников».
